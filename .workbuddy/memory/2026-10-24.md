# 2026-10-24

## u-dao-generator 升级到 JDK 25 + Spring Boot 4.1.2
- 项目原为 Spring Boot 2.0.6 + Java 8，升级到 **Spring Boot 4.1.2 + JDK 25**。
- pom.xml：parent 4.1.2；java.version=25；mysql `com.mysql:mysql-connector-j:26.7.0`（注意 2026 年起改日历版本号）；fastjson→`com.alibaba.fastjson2:fastjson2:2.0.66`；guava 33.7.2-jre；lombok 由 Boot BOM 管理（1.18.48）；spring-boot-admin 4.1.4（经 BOM import）；thymeleaf/web 改用 spring-boot-starter-thymeleaf + spring-boot-starter-web；阿里云仓库改 https。
- MySQLManager.java：`com.mysql.jdbc.*` 类已删除，改用 `java.sql.Connection/PreparedStatement`，驱动类改为 `com.mysql.cj.jdbc.Driver`，JDBC URL 增加 `useSSL=false&allowPublicKeyRetrieval=true`。
- application.properties：`spring.thymeleaf.mode` HTML5→HTML；`spring.resources.*`→`spring.web.resources.*`；删除 `spring.mvc.static-path-pattern=/static/**`（恢复默认 `/**`，修正 index.html 中 `/layui/**` 等根路径资源原本 404 的问题）。
- 测试类从 JUnit 4 迁移到 JUnit 5（Jupiter），删除 `com.umgsai.udaogenerator` 包下错误路径的重复测试类。
- Maven wrapper 3.5.4→3.9.9。
- **关键坑**：JDK 23+ 起 javac 不再自动运行 classpath 上的注解处理器（JDK-8321314），Lombok 必须显式声明到 maven-compiler-plugin 的 `annotationProcessorPaths`，否则 `@Slf4j`/`@Data` 生成的方法全部缺失，编译报“找不到符号 log / getColumnName”。已在 pom 中配置。
- 构建验证：用下载的 Temurin JDK 25.0.4.1（路径 `C:/Users/Shang/AppData/Local/Temp/jdk25dl/jdk-25.0.4.1+1`）执行 `mvn clean package`，BUILD SUCCESS，测试通过，产物 `target/u-dao-generator-0.0.1-SNAPSHOT.jar`（约 58MB）。本机默认 JDK 仍是 21，运行/构建本项目需用上述 JDK 25 路径或安装到系统中。
